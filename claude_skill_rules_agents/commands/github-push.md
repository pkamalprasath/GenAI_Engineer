Push the current project into a subfolder of an existing GitHub repository using a Python script (works even when bash/gh CLI is unavailable).

## Usage
`/github-push <github-url> <subfolder-name>`

Example:
```
/github-push https://github.com/pkamalprasath/GenAI_Engineer guardrails
/github-push https://github.com/pkamalprasath/GenAI_Engineer langchain
```

## Steps to Perform

### 1. Gather Information from $ARGUMENTS

Parse $ARGUMENTS for:
- `<github-url>` — full HTTPS URL of the target repository (e.g. `https://github.com/user/repo`)
- `<subfolder-name>` — name of the subfolder to create inside that repo (e.g. `guardrails`)

If either is missing, ask the user before proceeding.

### 2. Pre-Push Checklist (run /secret-scan first)

Before pushing ANYTHING to GitHub:
1. **Secret scan** — search all tracked files for:
   - `sk-proj-`, `sk-ant-` (OpenAI / Anthropic)
   - `hf_` (HuggingFace)
   - `gsk_` (Groq)
   - `pcsk_` (Pinecone)
   - `AKIA` (AWS)
   - `xoxb-`, `xapp-` (Slack)
   - `ghp_`, `github_pat_` (GitHub tokens)
   - `AstraCS:` (AstraDB)
2. **Check .gitignore** — must exclude: `venv/`, `.env`, `__pycache__/`, `.ipynb_checkpoints/`
3. **Verify .env files** — all .env files must contain only placeholder values
4. **Verify .env.example exists** — required before pushing

If any real secrets are found, STOP and run `/secret-scan` to fix them first.

### 3. Write and Run a Python Push Script

**IMPORTANT:** Use a Python script for all git operations because:
- The bash shell may be non-functional on Windows
- PowerShell `$variable` syntax gets mangled when passed through the JSON/shell layer
- Python subprocess is reliable and handles paths correctly

Generate the script as `push_to_github.py` in the current project root, then run it.

#### Script Template

```python
"""
Push <project> content to <github-url> under subfolder '<subfolder-name>'.
Auto-generated by /github-push command.
"""
import os
import shutil
import subprocess

SRC        = r"<absolute-path-to-current-project>"
CLONE_DIR  = r"C:\Temp\<repo-name>_push"
REMOTE_URL = "<github-url>.git"
SUBFOLDER  = "<subfolder-name>"

# Dirs/files to ALWAYS skip
EXCLUDE_DIRS = {
    ".git", "venv", ".venv", "env",
    "__pycache__", ".ipynb_checkpoints",
    "node_modules", "dist", "build",
    "reports",          # Garak/generated reports
    "chroma_db",        # vector store
    "faiss.index",
}
EXCLUDE_FILES = {
    "push_to_github.py",
    "fix_project.py",
    "rename_and_commit.py",
    "organize.py",
    "cleanup_envs.py",
    ".DS_Store",
}
EXCLUDE_EXTENSIONS = {".pyc", ".pyo", ".db", ".sqlite", ".sqlite3", ".faiss"}

def copy_tree(src, dst):
    """Recursively copy src to dst, skipping excluded dirs/files."""
    os.makedirs(dst, exist_ok=True)
    for item in os.listdir(src):
        if item in EXCLUDE_DIRS or item in EXCLUDE_FILES:
            print("  [SKIP]", item)
            continue
        s = os.path.join(src, item)
        d = os.path.join(dst, item)
        if os.path.isdir(s):
            copy_tree(s, d)
        else:
            ext = os.path.splitext(item)[1].lower()
            if ext in EXCLUDE_EXTENSIONS:
                continue
            shutil.copy2(s, d)

def run(cmd, cwd=None, check=True):
    r = subprocess.run(cmd, cwd=cwd, capture_output=True, text=True)
    if r.stdout.strip():
        print(r.stdout.strip()[:600])
    if r.returncode != 0 and r.stderr.strip():
        print("[ERR]", r.stderr.strip()[:400])
    if check and r.returncode != 0:
        raise RuntimeError(f"Command failed: {' '.join(cmd)}")
    return r

# ── 1. Clean previous clone and re-clone ─────────────────────────────────────
print("=== Step 1: Clone", REMOTE_URL, "===")
if os.path.exists(CLONE_DIR):
    shutil.rmtree(CLONE_DIR)
run(["git", "clone", REMOTE_URL, CLONE_DIR])

# ── 2. Copy current project into subfolder ────────────────────────────────────
print(f"\n=== Step 2: Copy content into {SUBFOLDER}/ ===")
dest = os.path.join(CLONE_DIR, SUBFOLDER)
if os.path.exists(dest):
    print(f"[WARN] {SUBFOLDER}/ already exists in repo — will overwrite")
copy_tree(SRC, dest)
total = sum(len(files) for _, _, files in os.walk(dest))
print(f"Copied {total} files into {SUBFOLDER}/")

# ── 3. Git config ─────────────────────────────────────────────────────────────
run(["git", "config", "user.email", "kamal@genai.dev"], cwd=CLONE_DIR, check=False)
run(["git", "config", "user.name", "Kamal Prasath"], cwd=CLONE_DIR, check=False)

# ── 4. Stage ──────────────────────────────────────────────────────────────────
print("\n=== Step 3: Stage files ===")
run(["git", "add", SUBFOLDER], cwd=CLONE_DIR)
run(["git", "status", "--short"], cwd=CLONE_DIR)

# ── 5. Commit ─────────────────────────────────────────────────────────────────
print("\n=== Step 4: Commit ===")
commit_msg = (
    f"feat: add {SUBFOLDER} - <one-line description>\n\n"
    f"- <bullet point summary of what was added>\n\n"
    "Co-Authored-By: Claude Sonnet 4.6 <noreply@anthropic.com>"
)
run(["git", "commit", "-m", commit_msg], cwd=CLONE_DIR)

# ── 6. Push ───────────────────────────────────────────────────────────────────
print("\n=== Step 5: Push ===")
# Try main first, fall back to master
r = run(["git", "push", "origin", "main"], cwd=CLONE_DIR, check=False)
if r.returncode != 0:
    run(["git", "push", "origin", "master"], cwd=CLONE_DIR)

print(f"\n[SUCCESS] https://github.com/<user>/<repo>/tree/main/{SUBFOLDER}")
```

### 4. Customize the Script Before Running

Before executing, fill in the actual values:
- `SRC` — get from `os.getcwd()` or the user's working directory
- `CLONE_DIR` — use `C:\Temp\<repo-name>_push` (unique temp path)
- `REMOTE_URL` — the GitHub URL with `.git` appended
- `SUBFOLDER` — from $ARGUMENTS
- Commit message — write a meaningful summary of what's being pushed
- Git user email/name — use the user's GitHub identity (`pkamalprasath` / `kamal@genai.dev`)

### 5. Run the Script

```bash
python push_to_github.py
```

Or via PowerShell if needed:
```
powershell -Command "python push_to_github.py"
```

### 6. Verify Success

After the script completes:
1. Check the printed `[SUCCESS]` URL
2. Verify the subfolder appears in the repo at the correct path
3. Confirm no `.env` secrets were accidentally committed:
   - Check: `git show --stat HEAD` in the clone dir

### 7. Clean Up

After a successful push:
1. Delete the temp clone directory (`C:\Temp\<repo-name>_push`)
2. Delete `push_to_github.py` from the project root
3. Report the live GitHub URL to the user

### 8. Report

Show:
- Number of files pushed
- Live GitHub URL: `https://github.com/<user>/<repo>/tree/main/<subfolder>`
- Any files that were skipped (and why)
- Confirmation that no `.env` secrets were pushed

## Common Issues and Fixes

| Issue | Fix |
|---|---|
| `Authentication failed` | User needs to set up git credentials or use a PAT token |
| `src refspec main does not match` | Try `master` branch instead of `main` |
| `Repository not found` | Check URL spelling; verify repo is public or user has access |
| `Push rejected (non-fast-forward)` | Pull first: add `git pull origin main` before push |
| `bash` commands fail on Windows | Always use Python subprocess — never raw bash for git operations |
| `$variable` mangled in PowerShell strings | Write Python script to disk, run via `python script.py` |
| Large files rejected | Add to `.gitignore` before staging (venv, reports, *.pkl) |

## Directories Always Excluded

These are NEVER pushed regardless of project type:

```python
ALWAYS_SKIP = {
    ".git",              # Git metadata
    "venv", ".venv",     # Virtual environments (hundreds of MB)
    "__pycache__",       # Python bytecode
    ".ipynb_checkpoints",# Jupyter autosave
    "node_modules",      # Node packages
    "reports",           # Generated scan reports
    "chroma_db",         # Vector store data
    "faiss.index",       # FAISS index
}
```
