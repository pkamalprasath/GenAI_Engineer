# Text preprocessing with NLTK

Course notebooks covering the basic text-preprocessing steps with NLTK.

| Notebook | Topic |
|---|---|
| `01_Tokenizer_with_nltk.ipynb` | Sentence and word tokenisation |
| `02_Stemming.ipynb` | Stemming |
| `03_Lemmatizer.ipynb` | Lemmatisation |
| `04_StopWords_with_nltk.ipynb` | Stop-word removal |
| `05_PartOfSpeech.ipynb` | Part-of-speech tagging |
| `06_Named_entity_recognition.ipynb` | Named entity recognition |

Sample input texts are in [`input/`](./input/).

**Source:** course labs from the Udemy course *Complete Generative AI Course With LangChain and Hugging Face* (completed 20 Jan 2026).
