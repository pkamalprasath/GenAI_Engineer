# Word representations

Course notebooks moving from sparse to dense text representations.

| Notebook | Topic |
|---|---|
| `1.BagOfWords.ipynb` | Bag of words (scikit-learn `CountVectorizer`) |
| `2.N-Grams.ipynb` | N-grams |
| `3.TF_IDF.ipynb` | TF-IDF |
| `4.Word2Vec.ipynb` | Word2Vec with gensim |

The first three notebooks use the [SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection) dataset, which is not committed. Download it and place the file at `input/SMSSpamCollection` next to the notebooks.

**Source:** course labs from the Udemy course *Complete Generative AI Course With LangChain and Hugging Face* (completed 20 Jan 2026).
